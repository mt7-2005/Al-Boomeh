## Run it

1. Configure the database connection string.
2. Apply the database migrations.
3. Configure the `JwtKey`.
4. Run the `Al-BoomehAPI`.

### Finding a Customer OTP

When requesting an OTP for a customer, check the API logs.
It will show in the logs like:

```
SMS sent to 0780785454 The OTP : 54545
```
